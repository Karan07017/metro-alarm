# 🚇 Metro Alarm

A hybrid GPS + time-based alert system that notifies commuters one station before their destination — solving the real-world problem of unreliable GPS signals in underground metro tunnels.

## 🎯 Problem Statement

GPS signals are unreliable in underground metro tunnels, making pure location-based tracking apps fail for commuters. Metro Alarm uses a hybrid approach — GPS when available, time-based estimation as fallback — to reliably alert users before their destination.

## 🛠️ Tech Stack

- **Backend:** Node.js, Express
- **Database:** MongoDB (Atlas)
- **APIs:** Geolocation API, Web Notifications API, Web Audio API, Vibration API
